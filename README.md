# HydroDome SCADA — ⚠️ ARCHIVED (permanent system)

> **This repo is archived.** It is the SCADA command-and-control mockup for the
> original **permanent** HydroDome installation (fixed zones of evenly-spaced,
> permanently-mounted towers fed from a municipal water main). The product has
> moved to the **mobile / trailer-deployed** system, so this mockup is kept for
> reference only and is no longer maintained.
>
> **Superseded by:**
> [`hydrodome-mobile-command`](https://github.com/TetonTopo/hydrodome-mobile-command)
> — the mobile Command & Control dashboard (two-pump failover, sequential
> one-gun-per-side firing, per-gun LoRa nodes, closed-loop nozzle pressure).

`index.html` is a single static SVG dashboard mockup (zones A–E, ~40 towers, all
running simultaneously off per-zone municipal feeds). Visual demo only.
